### Section 3: Step 1: Install TiviMate from Google Play

Open Google Play on the television device.Search for TiviMate IPTV Player.Check that the publisher matches the current official listing.Select Install.Open the application after installation.

Do not use an APK mirror or download code.

### Section 4: Step 2: Add the provider credentials

Choose the playlist or login method specified by the provider.Enter the server address and account details exactly as supplied.Give the account a recognisable, non-sensitive name.Allow the initial data load to complete.Confirm the account appears before changing other settings.

### Section 5: Step 3: Check the programme guide and favourites

Allow the first guide update to finish.Check the device time zone.Open a known category.Confirm programme times are sensible.Add frequently used items to favourites using the player controls.

### Section 6: Common errors

Login or playlist error

Check for copied spaces, incorrect capitalisation, an incomplete server address, expired credentials or a provider-side account restriction.

The programme guide is empty

Confirm that guide data is included with the provider account. Refresh once and check the device date and time. Repeated refreshes cannot create data the provider has not supplied.

Playback fails on one device

Record the device model, operating-system version, TiviMate version, error text and approximate time. Ask the provider whether that device is supported.

### Section 7: Who to contact

Contact the player publisher for installation, interface or player-account issues.

Contact the authorised provider for credentials, package availability, account status or provider-side guide data.

Provide an account reference and diagnostic context, never the complete password.
